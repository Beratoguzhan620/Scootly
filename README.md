# Scootly

Şehir içi elektrikli scooter paylaşım sisteminin backend'i. Clean Architecture prensipleriyle, .NET ile geliştirilmektedir.

## Nasıl Çalıştırılır

1. `.NET 8 SDK` kurulu olmalı.
2. `dotnet build` ile projeyi derle.
3. `dotnet run --project src/Scootly.Api` ile API'yi başlat.

Veritabanı bağlantısı henüz kurulmadı (11-14. günlerde eklenecek).
